# How to Use CyLabs

## How it's organized

CyLabs is grouped into ten sections that follow how security work is actually done:

1. **Foundations**: networking, operating systems, programming, labs and careers.
2. **Governance, Risk & Compliance**: risk, policy, frameworks and architecture principles.
3. **Offensive Security & Assessment**: the assessment lifecycle from scoping to reporting.
4. **Application Security**: web, API, mobile and IoT application testing.
5. **Cloud, DevSecOps & Platforms**: cloud security, pipelines, Kubernetes and containers.
6. **Security Operations & Defense**: SOC, threat hunting, IR, forensics and defensive controls.
7. **Specialized Domains**: mobile, IoT/OT/SCADA, hardware and reverse engineering.
8. **AI, ML & Data Science**: AI for security and security of AI.
9. **Industry Case Studies**: sector deep dives.
10. **Resources**: blogs, news, certifications and communities.

## Page status

* ✅ **Written**: the page has content.
* 🚧 **Coming soon**: the topic is planned; the page is a placeholder.

Every section page shows how many of its pages are written, so you can see at a glance where the depth is.

## Reading tips

* Use the **search** (Ctrl/Cmd + K) to jump straight to a tool or technique.
* The **"On this page"** panel on the right lists each page's headings.
* Commands are shown in code blocks you can copy with one click.
